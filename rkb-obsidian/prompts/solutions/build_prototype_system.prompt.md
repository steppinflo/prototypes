# Build Prototype System for RKB Obsidian

## Context
You can learn more about RKB Obsidian in @rkb-obsidian/docs/business/.

There is a solutions document for RKB Obsidian's internal portal for inventory management, parts ordering and tractor order fulfillment in @rkb-obsidian/docs/solutions/prototype.solution.md.
- supporting diagram @rkb-obsidian/docs/solutions/sketch_diagram.prototype.pdf.

## Request
Build out the initial prototype for this internal system based on the solutions doc.

To support this, you will need to build out a prototype data set to seed the system with. There is a starting data set available @rkb-obsidian/docs/synthetic_supply_chain_dataset.csv.

## Guidelines
- mock the models so the entire system can work without actually having developed an AI/ML model, since this is a prototype
- honor the solutions doc and the diagram
- the system/portal should be accessible over a web page/site
- the prototype should be able to run on any machine with a simple command to spin it up
- bias towards building in Javascript.

## Success Criteria
- The prototype implements the solutions doc
- the prototype can be run from any machine with a single command
